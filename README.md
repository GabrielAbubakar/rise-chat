# Rise Chat

A WhatsApp clone built with React Native and Expo.

## Tech Stack
- **Framework:** Expo & React Native
- **State Management:** Zustand
- **Data Fetching:** React Query & Axios
- **Styling:** TailwindCSS

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Development

You can start developing by editing the files inside the **src/app** directory. This project uses Expo Router for file-based routing.
